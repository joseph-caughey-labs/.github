Open-source and product engineering from [Joseph Caughey](https://github.com/josephcaughey). Most of the work here is about making AI-assisted software verifiable: specs that can be executed, judges that grade against explicit criteria, and checks that keep running after deploy.

### Validation and AI tooling

- [DirectiveAI](https://github.com/joseph-caughey-labs/DirectiveAI): compiles structured directives in a repo into scoped, policy-gated, auditable branches. TypeScript.
- [spec-eval](https://github.com/joseph-caughey-labs/spec-eval): grades LLM output against a written spec, with deterministic checks first and a cached model judge. Python.
- [schema-guard](https://github.com/joseph-caughey-labs/schema-guard): reports breaking changes between two versions of a JSON Schema or OpenAPI component, judged by which way the data flows. Go.
- [ai-agent-framework](https://github.com/joseph-caughey-labs/ai-agent-framework): agents with pluggable providers, memory and tools. TypeScript.
- [airport-inspection-platform](https://github.com/joseph-caughey-labs/airport-inspection-platform): layered validation with human review and a tamper-evident audit trail. TypeScript.

### Libraries

- [ledger-core](https://github.com/joseph-caughey-labs/ledger-core): double-entry ledger with exact money arithmetic, checked with property-based tests. Rust.
- [provably-fair-engine](https://github.com/joseph-caughey-labs/provably-fair-engine): verifiable randomness with HMAC-SHA256 and unbiased draws. TypeScript.
- [algorithms-ts](https://github.com/joseph-caughey-labs/algorithms-ts): data structures and algorithms with tests and benchmarks. TypeScript.
- [web-patterns-cookbook](https://github.com/joseph-caughey-labs/web-patterns-cookbook): auth, webhooks, pagination and other web patterns. TypeScript.

### Starters and infrastructure

- [react-rsc-saas-starter](https://github.com/joseph-caughey-labs/react-rsc-saas-starter) and [nuxt-edge-saas-starter](https://github.com/joseph-caughey-labs/nuxt-edge-saas-starter): SaaS starters for Next.js and Nuxt.
- [aws-cdk-stacks](https://github.com/joseph-caughey-labs/aws-cdk-stacks): CDK stacks for a static site, ECS Fargate and RDS.
- [firebase-superservice](https://github.com/joseph-caughey-labs/firebase-superservice): Firebase monorepo with Cloud Functions, rules and emulator tests.
- [gatsby-content-hub](https://github.com/joseph-caughey-labs/gatsby-content-hub): MDX content site with generated OG images.
